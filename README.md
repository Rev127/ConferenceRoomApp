# ConferenceRoomApp
Система управління конференц-залами для організацій, що дозволяє користувачам бронювати та керувати конференц-залами.

## Система

### Функціональність
- Бронювання конференц-залів;
- Перегляд доступності конференц-залів;
- Оновлення інформації про конференц-зали (додавання, редагування, видалення);
- Перегляд звітності про використання конференц-залів;
- Перегляд звітності про популярність конференц-залів.

### Особливості
- Задокументований API за допомогою Swagger;
- Механізм автентифікації та авторизації користувачів.
- Розрахунок ціни бронювання конференц-залів залежно від тривалості та часу бронювання;
- Додано ряд початкових даних.

### Технічні рішення
- Реалізований механізм аутентифікації та авторизації користувачів за допомогою ASP.NET Core Identity;
- Звязок з базою даних реалізовано за допомогою Entity Framework;
- Додано механізм обробки помилок;
- Реалізований механізм розрахунку ціни бронювання конференц-залів за допомогою поведінкового патерну Стратегія;
- Систему розбито на окремі шари для забезпечення кращої підтримки та розширюваності.

### Технології
- Platform: Visual Studio 2026, .NET 10.0;
- Programming Language: C#;
- Backend: ASP.NET Core, Entity Framework;
- Database: MySQL;

## Інструкція з запуску

### 1. Клонування репозиторію
```bash
git clone https://github.com/yourusername/ConferenceRoomApp.git
```

### 2. Налаштування бази даних
У файлі `appsettings.json` налаштуйте рядок підключення до вашої бази даних MySQL:
```json
"ConnectionStrings": {
  "DBConection": ". . ."
}
```

### 3. Міграції бази даних
Використайте Entity Framework для створення та застосування міграцій до бази даних. Виконайте наступні команди у терміналі:

- Створення міграцій:
```bash
dotnet ef migrations add <Назва_міграції>
```

- Застосування міграцій:
```bash
dotnet ef database update
```
